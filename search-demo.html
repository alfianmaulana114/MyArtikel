Usage Examples

Basic Search

// Initialize search component const search = new AdvancedSearch({ container: '#search-container', resultsContainer: '#search-results', enableAutocomplete: true, enableHistory: true, onSearch: (results, query) => { console.log(`Found ${results.total_count} results for: ${query}`); } });

Advanced Search with Filters

// Search with specific filters const results = await SearchService.search('machine learning', { status: 'published', tags: [1, 2, 3], date_from: '2024-01-01', date_to: '2024-12-31' }, { per_page: 50, page: 1 });

Quick Search for Instant Results

// Get instant search results const quickResults = await SearchService.quickSearch('AI', 5); console.log(`Quick search returned ${quickResults.results.length} results`);

Search Analytics

// Get search analytics const analytics = await SearchService.getAnalytics(30); console.log(`Total searches: ${analytics.analytics.total_searches}`); console.log(`Click-through rate: ${analytics.analytics.click_through_rate}%`);

Integration Guide

Prerequisites: Make sure you have run the database migrations and the search indexing is complete.

Step 1: Include Required Files

<!-- Include Font Awesome for icons --> <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.0.0/css/all.min.css"> <!-- Include search components --> <script src="/js/search/SearchService.js"></script> <script src="/js/search/AdvancedSearch.js"></script>

Step 2: Initialize Search Component

document.addEventListener('DOMContentLoaded', function() { const search = new AdvancedSearch({ container: '#search-container', resultsContainer: '#search-results', enableAutocomplete: true, enableHistory: true, enableFilters: true, enableAnalytics: true, onSearch: function(results, query) { console.log('Search completed:', results); updatePerformanceStats(results); }, onResultClick: function(result, query) { console.log('Result clicked:', result); // Handle result navigation } }); });

Step 3: Configure Search Options

// Customize search behavior const searchOptions = { // UI Configuration debounceTime: 300, // Delay before search (ms) minChars: 2, // Minimum characters for search maxHistoryItems: 10, // Max items in search history showResultCount: true, // Show result count highlightMatches: true, // Highlight search terms in results // Feature Toggles enableAutocomplete: true, // Enable search suggestions enableHistory: true, // Enable search history enableFilters: true, // Enable advanced filters enableAnalytics: true, // Enable search analytics // Callbacks onSearch: function(results, query) { // Called when search completes }, onResultClick: function(result, query) { // Called when result is clicked } };
